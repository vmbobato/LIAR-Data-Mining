# LIAR Dataset - Data Mining Project

## Overview

This project explores the LIAR dataset, a collection of 12,791 political statements labeled with six levels of truthfulness from the PolitiFact fact-checking archive. The goal is to apply core data mining techniques from the course while extending the analysis with modern NLP methods.

The project focuses on understanding patterns in truthfulness, evaluating modeling approaches, and analyzing bias and generalization in political fact-checking data.

## Dataset  

Source: PolitiFact Fact-Checking Archive  
Introduced in: Wang, W. Y. (2017). “Liar, Liar Pants on Fire”
